# L2 Interlude Farm Bot (с уведомлениями в Telegram о смерти)

Внешний фарм-бот для Lineage 2 (анализ полос HP на экране через `mss` + `OpenCV` и эмуляция клавиш через `pydirectinput`). Не читает память клиента и не вмешивается в работу защиты игры.

---

## 1. Установка

Требуется **Windows 10/11** и **Python 3.11+**.

```powershell
pip install -r requirements.txt
```

> Запускай терминал (PowerShell / CMD) **от имени Администратора**, иначе Windows не позволит передавать нажатия клавиш в окно игры.

---

## 2. Настройка Telegram-бота и `secrets.yaml`

1. В Telegram открой **@BotFather** → отправь `/newbot` → укажи имя и username бота → скопируй полученный **token** (вида `123456789:AAH...`).
2. Перейди в созданного бота и нажми **Start** (или напиши любое сообщение).
3. Узнай свой **chat_id**: открой в браузере ссылку:
   `https://api.telegram.org/bot<ТВОЙ_ТОКЕН>/getUpdates`
   и найди число в `"chat":{"id":123456789,...}`.
4. Открой файл `secrets.yaml` (создан по шаблону `secrets.example.yaml`) и впиши свои данные:
   ```yaml
   telegram:
     token: "123456789:AAH..."
     chat_id: "123456789"
   ```
   *(Либо задай переменные окружения `L2BOT_TG_TOKEN` и `L2BOT_TG_CHAT_ID` — они имеют высший приоритет).*

### Проверка связи с Telegram

```powershell
python test_telegram.py
```
В Telegram должны прийти тестовое сообщение и скриншот твоего экрана.

## 3. Калибровка полос HP

1. **Поиск координат и цвета:**
   ```powershell
   python calibrate.py
   ```
   - Наведи курсор на левый край красной полосы HP **цели**, запиши `x`, `y`, затем на правый край — вычисли ширину `w = x2 - x1`. Пропиши в `target_bar` в `config.yaml`.
   - Аналогично наведи курсор на полосу HP **своего персонажа** и запиши координаты в `player_bar` в `config.yaml`.

2. **Проверка полосы HP цели:**
   ```powershell
   python calibrate.py roi
   ```
   Сохраняет увеличенный фрагмент в `roi_debug.png` и показывает процент HP цели в реальном времени (с выделенным живым мобом должно быть `~100%`, без цели `~0%`).

3. **Проверка полосы HP персонажа:**
   ```powershell
   python calibrate.py player
   ```
   Сохраняет `roi_player_debug.png` и показывает HP персонажа в реальном времени (у живого персонажа с полным здоровьем должно быть `~100%`).

4. **Снятие полного скриншота (опционально для шаблона кнопки воскрешения):**
   ```powershell
   python calibrate.py shot
   ```
   Сохраняет `screen.png`, из которого можно вырезать кнопку «В деревню» в `templates/revive.png` (если включён `death.use_template: true`).

## 4. Запуск и горячие клавиши

```powershell
python bot.py
```

Бот всегда стартует **на паузе**. Переключись в окно игры и используй горячие клавиши (настраиваются в `config.yaml`):

| Клавиша по умолчанию | Действие |
|---|---|
| `Ctrl+Alt+S` | Старт / Пауза (`keys.toggle`) |
| `Ctrl+Alt+D` | Симуляция смерти / воскрешения (`keys.simulate_death`) |
| `Ctrl+Alt+Q` | Полная остановка и выход (`keys.stop`) |

### Проверка сценария смерти без реальной смерти (`Ctrl+Alt+D`)

1. Запусти `python bot.py` и нажми `Ctrl+Alt+D`:
   - Бот отпустит все клавиши, снимет скриншот и пришлёт уведомление о смерти в Telegram.
   - Каждые `repeat_every_sec` секунд будут приходить напоминания.
2. Нажми `Ctrl+Alt+D` второй раз:
   - Бот зафиксирует «воскрешение», отправит сообщение `✅ Персонаж снова жив...` и встанет на паузу.

## 5. Параметры `death`, `telegram` и `stall_alert` в `config.yaml`

| Параметр | По умолчанию | Описание |
|---|---|---|
| `death.enabled` | `true` | Включить определение смерти персонажа |
| `death.check_interval` | `0.5` | Интервал (сек) между чтениями полосы HP персонажа |
| `death.confirm_reads` | `3` | Сколько проверок подряд `HP <= empty_threshold` нужно для подтверждения смерти |
| `death.empty_threshold` | `1.0` | Порог HP (%), ниже или равно которому полоса считается пустой |
| `death.alive_threshold` | `10.0` | Порог HP (%), выше которого персонаж считается живым |
| `death.revive_confirm_sec` | `3` | Сколько секунд подряд `HP > alive_threshold` нужно для подтверждения воскрешения |
| `death.auto_resume` | `false` | `false` — после воскрешения остаться на паузе; `true` — сразу продолжить фарм |
| `death.use_template` | `false` | Дополнительно искать шаблон окна воскрешения (`templates/revive.png`) |
| `telegram.enabled` | `true` | Включить отправку уведомлений в Telegram |
| `telegram.send_screenshot` | `true` | Прикладывать скриншот экрана к сообщению о смерти |
| `telegram.timeout_sec` | `10` | Таймаут сетевого запроса к Telegram API (сек) |
| `telegram.retries` | `3` | Количество попыток отправки при сбое сети (паузы 1с → 2с → 4с) |
| `telegram.repeat_every_sec` | `60` | Интервал повторных напоминаний (сек), пока персонаж мёртв |
| `telegram.max_repeats` | `10` | Максимальное число повторных напоминаний за одну смерть |
| `telegram.notify_on_start` | `false` | Отправлять `🟢 Бот запущен` при первом снятии с паузы |
| `telegram.notify_on_stop` | `false` | Отправлять `🔴 Бот остановлен` и статистику при выходе |
| `stall_alert.enabled` | `false` | Уведомлять в Telegram, если долго нет убийств |
| `stall_alert.minutes` | `10` | Через сколько минут без убийств отправлять алерт |

## 6. Частые проблемы

- **При снятии с паузы пишет `⚠ Калибровка player_bar неверна или персонаж мёртв — определение смерти ОТКЛЮЧЕНО`:**
  Запусти `python calibrate.py player` и проверь картинку `roi_player_debug.png`. Координаты `player_bar` должны попадать строго на красную часть полосы HP персонажа, а окно игры не должно быть перекрыто другими окнами.
- **Бот не нажимает клавиши в игре:**
  Запусти консоль (PowerShell / CMD) **от имени Администратора**. Игра должна быть в оконном режиме или «Окно без рамки» (Borderless).
- **`test_telegram.py` пишет ошибку чата (`chat not found`):**
  Убедись, что ты открыл своего бота в Telegram и нажал кнопку **Start**, а `chat_id` в `secrets.yaml` скопирован без опечаток.
